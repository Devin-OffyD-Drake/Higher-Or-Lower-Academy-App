# :arrow_upper_right: Higher Or Lower Academy App :arrow_lower_right:

A .NET 10 CRUD app created with WinForms to access and manage a database for a school training players of the guessing game Higher or Lower. It will come with various reporting features, and different functionality based on user type.

Currently in a non-functional state; steady updates will be developed to create a 1.0 version based on an internal spec of desired features.

## :hourglass_flowing_sand: README COMING SOON! :hourglass_flowing_sand:

## Note
This is a training / demonstration project, designed only to work with a certain local SQL Server Instance, so it has no functionality when deployed elsewhere.
This will be rectified in the planned sequel project, "Higher or Lower Academy Online" utilising a cloud database.
